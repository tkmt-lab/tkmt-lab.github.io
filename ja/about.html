研究の進め方・感謝・連絡

どう確かめているか

  • 形式証明：Lean 4 という証明の検査系が、証明の全段階を機械で確かめます。その証明が、別の者が先に書いておいた主張文と同じことの証明であることも、Comparator という道具で確かめています。論文から形式版へ移す段階で、Lean に含まれない部分も明記しています。
  • 独立な導出：別のチームが、もう一方の証明やコードを見ずに、別の証明を書きました。主張・期待される結果・数学的な準備まで伏せられていたとは限りません。共有したものは各研究の記録に示します。別実装による検査やAIによる読解とは区別します。
  • AI による点検：AI が文章の証明を読み、一部を計算し直しました。人間の査読とは区別します。
  • 有限の計算：全数を調べた検査と、一部を抽出した検査を区別し、調べた範囲を明記しています。

論文 1・2・6 の主な定理は、証明を除いた Lean の主張文として、別の主張文集（doi:10.5281/zenodo.23594152）にもまとめています。各主張文は固定した commit の証明にリンクしています。主張文集をビルドしても証明は検査されません。

人間の専門家による査読は受けていません。新規性を含め、何を確かめ、何が未確認かは、各リポジトリに主張ごとに記しています。訂正も公開しています。

すべての成果の主張、証拠の種類、確かめ直すコマンドは、機械で読める一つのファイルにまとめています：成果の目録（catalog.json）。AI向けの短い索引（英語）もあります。

検査の種類ごとのやり方、それで言えること、残ることを、他の研究でも使える手順としてまとめています：成果をどう確かめるか。

研究の進め方

AI（OpenAI の Codex と Anthropic の Claude Code）が、探索、独立な検証、文献の調査、形式化を、別々のチームとして担っています。私（滝本竜彦）が方向を決め、判断し、公開する成果、その来歴、明記した検証の範囲と限界に責任を持ちます。AI は著者に入れていません。

元になった研究への感謝

これらの結果は、この分野を切り開いてきた研究者の方々の仕事の上にあります。フラーレンの問いは、A. Bille、V. Buchstaber、E. Spodarev による未解決問題の一覧から生まれました。調べた形は、M. Goldberg と H. S. M. Coxeter の名を冠した構成と、それを広げた M. Dutour Sikirić と M. Deza の仕事、そして J. E. Graver の目録によるものです。K. Kutnar と D. Marušič によるフラーレンの巡回辺連結性の研究、J. R. Büchi、C. C. Elgot、B. A. Trakhtenbrot による論理と有限オートマトンを結ぶ定理、Lean 4 と mathlib、Comparator と独立な検査器を作った方々の仕事も使わせていただきました。

Bell 不等式の仕事は、R. Gill の問いと、C. Staufenbiel が公開した面のリストと道具、その土台になった S. Lörwald と G. Reinelt の PANDA の上にあります。

分散のある Hawking 放射の仕事は、W. G. Unruh の音のブラックホールの考えと、S. Corley と T. Jacobson、W. G. Unruh と R. Schützhold、J. Macher、A. Coutant、S. Finazzi、R. Parentani、U. Leonhardt と S. Robertson、Y. Himemoto と T. Tanaka、A. Moreno-Ruiz と D. Bermudez、A. Coutant と S. Weinfurtner、そして比べる相手とした有効地平線の結果を出した F. Del Porro、S. Liberati、M. Schneider の仕事の上にあります。

感染症のモデルの仕事は、B. Pant、O. Saucedo、G. Pogudin の問いと予想、そして識別可能性の微分代数の結果を築いた A. Ovchinnikov、G. Pogudin、P. Thompson と、H. Hong、A. Ovchinnikov、G. Pogudin、C. Yap の仕事の上にあります。

Heesch 数の仕事は、H. Heesch の問題と、C. S. Kaplan の研究（すべての層をまとめた SAT による定式化、データ、heesch-sat のソフトウェア）の上にあります。問い、Hc と Hh の定義、調べた形、比べた値は、すべてそこから来ています。C. Mann の解説と、C. Mann と B. C. Thomas による辺に印のあるポリフォームの計算、A. Fontaine と B. Bašić の構成、Heesch 数に初めて確かめられる証明書を付けた Layr-Labs/Eigen の Heesch challenge とその参加者の方々、N. Wetzler、M. Heule、W. Hunt の drat-trim、A. Biere の CaDiCaL と Lingeling、G. Audemard と L. Simon の Glucose、A. Ignatiev、A. Morgado、J. Marques-Silva の PySAT、C. Sinz の逐次カウンタ、そして形式化の手本にした C. Codel、J. Avigad、M. Heule の検証された SAT 符号化と、B. Subercaseaux らによる空の六角形の数の検証の仕事も使わせていただきました。

結晶のネットの識別テストは、M. O'Keeffe、M. A. Peskov、S. J. Ramsden、O. M. Yaghi の RCSR（Reticular Chemistry Structure Resource）と、それぞれのネットを最初に記述した研究者の方々の仕事の上にあります。使ったネット、頂点の軌道、座標は、すべてそこから来ています。成長する配位殻をグラフとして比べ、どの殻まで一致するかを測る考えは V. A. Blatov と D. M. Proserpio によるもので、r_min はこの種の測定です。周期的なものを含む点群で、距離を使う WL やグラフニューラルネットワークが見分けられない組は、S. N. Pozdnyakov と M. Ceriotti が示しました（そちらは距離を使い、こちらはグラフの形だけを使います）。プログラムが読む空間群の表は、O. Delgado-Friedrichs の Gavrog のものです。

主張文集では、Formal Conjectures Authors によるファイルの形式と、分類・分野・証明へのリンクを記す属性を使わせていただきました。

ブールネットワークの反例集は、モチーフを避けるアトラクターがなぜ珍しいのかを問い、対照に使った例 7・8 を示した S. Pastva、K. H. Park、O. Huvar、J. C. Rozum、R. Albert と、試した条件の元になった仲介の条件と射影の補題を示した E. Tonello と L. Paulevé の仕事に負っています。

二次の質量作用系の項数の仕事は、N. Yeung と R. Erban による分類と、項数をどこまで減らせるかという問いを出発点としています。幾何の枠組みは、L. S. Lyagina と T. A. Newton による分類と不変直線の記述に基づいています。

二網の証明書と375網の上限の仕事は、固定リスト、Example 4の二つの例外、上限の主張、373/2の安定分類、Lemma 3の行列式による判定を与えたXiaoxian TangとJiandong Zhangの研究に基づいています。Angélica TorresとElisenda Feliuによる行列式への還元と安定性の交替、Murad BanajiとElisenda Feliuによる正平衡点の幾何と上限、Murad BanajiとCasian Panteaによる非退化な多定常性の継承の結果も使わせていただきました。

RNAの設計可能性の限界は、Théo Boury、Laurent Bulteau、Yann PontyによるmaxStacksの枠組みと問い、DRAT-trimとCakeML/cake_lprの開発者の方々の仕事の上にあります。挙げた著者は、この研究に参加したり推薦したりしたわけではありません。
